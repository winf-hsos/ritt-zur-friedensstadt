# Ritt zur Friedensstadt

Eine kleine Lern-App für Kinder der 4. Klasse in Osnabrück. Sie hilft beim Üben der Stadtgeschichte für den Sachunterricht und das Steckenpferdreiten: von der Furt an der Hase über Karl den Großen, die Domburg und die mittelalterliche Stadt bis zur Reformation, zum Dreißigjährigen Krieg und zum Westfälischen Frieden.

**App öffnen:** https://winf-hsos.github.io/ritt-zur-friedensstadt/

## Was die App kann

- 158 Fragen an 8 Stationen, dazu die Modi Probearbeit, Jahreszahlen-Profi und Fehler-Training
- Neun Antwortarten: Auswahl, Jahreszahlen und Wörter eintippen, Reihenfolge legen, Verbinden, Einsortieren, Lückentext, Mehrfachauswahl und freie Erklärung mit Selbstkontrolle
- Tipps mit Textauszügen und Bildern aus den Arbeitsblättern
- Taler, Ränge, Medaillen und eine Elternansicht mit dem Lernfortschritt
- Fortschritt als Datei oder Code sichern, auf einem anderen Gerät wiederherstellen und bei Bedarf zurücksetzen

Der Fortschritt wird nur im Browser auf dem eigenen Gerät gespeichert (localStorage). Es werden keine Daten an einen Server geschickt. Über „Für Eltern“ lässt er sich sichern und wiederherstellen.

## Quellen

Die Inhalte beruhen auf Arbeitsblättern zur Osnabrücker Stadtgeschichte aus dem Sachunterricht einer 4. Klasse und auf den Projektblättern „Osnabrück – Die Friedensstadt“ der Stadt Osnabrück (Inhalt und Konzept: Jana Cordes und Silke Grade, Zeichnungen: Manila Bartnik), abrufbar unter https://friedensstadt.osnabrueck.de/de/friedenlebenjetzt/frieden-erleben/steckenpferdreiten/. Die Bilder sind daraus entnommen. Die Rechte an diesen Materialien liegen bei den jeweiligen Urheberinnen und Urhebern; die App ist ein privates, nicht kommerzielles Lernangebot.

Die Antworten können im eigenen Unterricht etwas anders formuliert sein.

## Technik

Reines HTML, CSS und JavaScript ohne Abhängigkeiten. Die Fragen stehen in `daten.js`.
